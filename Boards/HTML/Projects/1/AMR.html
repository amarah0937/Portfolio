AMR

Project Name: All your Medical Resources Project Description: I would like to create an AMR platform that makes it easy for doctors to add medical information to patient profiles. Teachers and school nurses don't have a secure, automated, easy way to store updated student medical information. Target Audience: Doctors, nurses, and medical clerks Project Innovation: JavaScript is useful for making a website dynamic, making it easy to retrieve information like patient records. Platforms: Any browser
