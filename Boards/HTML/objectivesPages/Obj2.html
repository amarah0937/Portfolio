The projects in Objective 1 were built using Figma and Visual Studio code. These projects were built using Visual Studio and GDB Online Debugger, and compared to the HTML and CSS of the previous objective, these projects used C++ and Java.

Embedded programming is software written for hardware systems and electronics. These projects under this objective target robotics systems and tackle interfacing with electronic devices.

Project #1:

This bingo game was written in C++ and built in Visual Studio. The game randomly generates a combination of letters and numbers to call out a bingo square. The user can interact with the buttons to select the called out combination, and compete against their friends to get to BINGO first.

Project #2:

This text-based game was written in Java in the GDB Online Debugger IDE. The player is tasked with caring for a cafe of cats daily, feeding and playing with them, to earn bells. At the end of each day, the player can spend these bells in the power ups shop to gain treat or bell multipliers. Players can compete with their friends to complete the most days, and earn the highest score.

Project #3:

This is a navigational code I used for our small bot last VEX season. It works by recording the movement of the robot, tracking the voltage output of each motor, and saves these events as motor commands to a text file. The resulting text file could then be ran as instructions for the robot to repeat the recored the movement. This was used to tackle the challenge of autonomous movement. This code was saved to the VEX brain and the text file was automaticaally written to an SD card.

Project #4:

This code was a project I worked on in Internet of Things. This code was written in Arduino then uploaded to the M5Core2. This program tracks the output of the IMU sensors on the M5Core2 to track the position of the device. If the program detects a sudden and large change in velocity, the screen of the device updates with a warning message to alert the user of a possible drop.
