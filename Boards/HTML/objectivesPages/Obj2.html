Objective 2

Demonstrate software development skills using more than one programming language and development environment.

Bingo application where random combinations of letters and numbers are generated and the user has to fill their card.
I created a text-based game with the theme of a cat cafe.

The projects in Objective 1 were built using Figma and Visual Studio code. These projects were built using Visual Studio and GDB Online Debugger, and compared to the HTML and CSS of the previous objective, these projects used C++ and Java.

Project #1:

This bingo game was written in C++ and built in Visual Studio. The game randomly generates a combination of letters and numbers to call out a bingo square. The user can interact with the buttons to select the called out combination, and compete against their friends to get to BINGO first.

Project #2:

This text-based game was written in Java in the GDB Online Debugger IDE. The player is tasked with caring for a cafe of cats daily, feeding and playing with them, to earn bells. At the end of each day, the player can spend these bells in the power ups shop to gain treat or bell multipliers. Players can compete with their friends to complete the most days, and earn the highest score.
